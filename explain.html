4. Architecture Walkthrough

The JARVIS application is an Electron desktop app serving a native HTML/CSS/JS frontend. The backend integrates heavily with a dual-engine AI pipeline (Cloud Groq vs Local Ollama). The architecture heavily leverages Electron's IPC system to safely bridge the sandboxed renderer to the secure node main process.

The AI Tool Execution Pipeline

When the AI decides to call a tool (like `web_search`), the LLM outputs a JSON payload. The backend `main/ai.js` intercepts this JSON, executes the local Node.js function natively, appends the result to the memory array, and automatically pings the LLM again to synthesize the findings.
