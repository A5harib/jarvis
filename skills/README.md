# JARVIS AI Skills Directory

This directory is reserved for custom AI capability modules and function-calling tools.

## Planned Structure

In future updates, each sub-folder here will represent a distinct skill (e.g., system control, web scraping, automation, notifications) exposing standardized JSON schemas and logic handlers.

- `/system`: Commands for interaction with the host OS.
- `/agent`: Subagent workflows and conversation management.
- `/apis`: Third-party service integrations.
